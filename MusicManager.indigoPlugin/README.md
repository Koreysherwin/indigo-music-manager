# Music Manager

Unified Indigo music device for Spotify, Apple Music, VLC, and Airfoil Satellite.

Version 1.2.5 adds Airfoil Satellite support via the Airfoil Satellite Indigo plugin.


### 1.2.7
Apple Music picker now accepts known plugin id/name variants and local rebuilds.

## Upgrade note (1.2.8)
The plugin identifier is now `com.sherwinsound.musicmanager`. Back up Indigo before migrating; existing devices and actions using the old identifier may need to be recreated or reassigned. Disable the old plugin before enabling the new one.
